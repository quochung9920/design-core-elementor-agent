# CSS Fallback Policy

Use custom CSS only when Elementor controls cannot represent the required behavior.

A CSS fallback must:

- be scoped to the widget or component
- have a documented reason
- be compatible with the current Elementor capability report
- be traceable to an unsupported behavior or browser rendering requirement

Do not use custom CSS for layout that can be expressed through native container, grid, flexbox, spacing, and typography controls.
