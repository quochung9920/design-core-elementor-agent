# Elementor Mapping

## Priority order

1. Global design system
2. Existing component registry entry
3. Existing custom widget
4. Native Elementor Container
5. Native widget
6. Elementor Pro widget
7. Native content controls
8. Native style controls
9. Responsive controls
10. Nested containers
11. Component reuse
12. Loop-backed dynamic data
13. Scoped CSS fallback
14. Custom widget
15. Raw HTML widget

## Mapping principle

Map source visual intent to the closest native Elementor representation before introducing custom code.
