# Visual QA

Perform QA at desktop, tablet, and mobile breakpoints.

Check:

- layout consistency
- spacing parity
- typography fidelity
- border radius and shadows
- image fitting
- overflow and clipping
- CTA alignment
- repeated section consistency

When a discrepancy is found:

1. compare against source structure
2. inspect whether the issue is mapping, token, or responsive logic
3. fix in the nearest native control
4. retain scoped CSS only when absolutely needed
