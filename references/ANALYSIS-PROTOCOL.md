# Analysis Protocol

## Source analysis

- parse semantic blocks
- detect repeated structures
- inspect responsive breakpoints
- extract tokens and spacing values
- detect component opportunities

## Build strategy

- prefer native Elementor widgets and controls
- use components when pattern is reusable
- prefer loops for repeated dynamic data
- use custom widgets for complex interactions
- reserve CSS fallback for unsupported decoration effects

## Validation

- test layout against desktop/tablet/mobile reference
- check repeated patterns
- verify no unnecessary CSS drift
- ensure registry updates are recorded
